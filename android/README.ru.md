# Тишина на ролике

Установка Spotify:

    flatpak install flathub com.spotify.Client

Пакет `ru.stabilnoitochka.spotifyadmute` собирается командой `./gradlew :app:assembleDebug`. Запуск Gradle 8.7: JDK 17 или 21 (рекомендуется 21); JDK 25 не подходит. При необходимости задайте `JAVA_HOME` или `org.gradle.java.home` в локальном `gradle.properties`. Каталог Android SDK указывается в `local.properties` (`sdk.dir=...`). Образец: [`local.properties.example`](local.properties.example).

`adb install -r` ставит apk в личный профиль. Готовый файл: [spotifyadmute-1.0.apk](https://github.com/vramdibs/spotify-ad-mute/releases/download/v1.0/spotifyadmute-1.0.apk). Shelter не поддерживается из-за требований настроек специальных возможностей + ярлыка в меню приложений нет.

Пакет не из маркет, поэтому строка в «Спец. возможности» серая. На Android 17 это единственное разрешение: отдельного доступа к уведомлениям нет. Чтобы снять ограничение:

1. Настройки, приложения, все приложения, Spotify ad mute.
2. Три точки, «Разрешить доступ к настройкам».
3. Спец. возможности, скачанные приложения, Spotify ad mute. Переключатель больше не серый.
4. Включить переключатель. В диалоге «Разрешить сервису "Spotify ad mute" контролировать ваше устройство?» нажать «Разрешить».

Служба убавляет громкость музыки при появлении на экране ролика с таймером паузы через распознавание текста рекламы. Если экран выключен, то карточки Spotify в шторке нет, и текст уведомления читает та же служба специальных возможностей, в том числе у уже висящей паузы. Если уведомление еще пишет «Реклама», а сессия плеера уже называется песней, то громкость возвращается по сессии, когда система подключает слушателя уведомлений. Картинка рекламы в ленте громкость не меняет. Поток музыки в Android общий, поэтому на время ролика тише может стать и другое приложение в этом потоке. Интернета у пакета нет. Пока Spotify закрыт, служба событий не получает и громкость не трогает.

Проверка:

- экран с таймером паузы: звук на нуле, после экрана громкость становится прежней
- карточка в ленте при играющем треке: громкость не меняется
- выключить службу посреди ролика: громкость возвращается сразу
